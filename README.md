# Murmur

一个常驻 macOS 菜单栏的小工具，让翻译和语音输入随手可用。

- **框选翻译** — 按 `⌘E`，在屏幕上拖一个框，框里的文字立刻翻译出来。图片里的字也能读。
- **划词翻译** — 在任何 App 里选中文字，按 `⌥S` 直接翻译，不用复制粘贴、不用切窗口。
- **语音输入** — 在任何输入框里按 `Home`，说话，文字自动填进去。说完会自动去掉「嗯」「然后」这类口头语、去掉重复、把说错改口的只留最后一版，填进去的是能直接用的文字。

翻译结果显示在一个小浮窗里，可以钉住、可以拖动，不打断你手上的事。

## 你需要自备一个 API Key

**Murmur 不含任何账号或额度。** 翻译和语音识别用的是你自己的 AI 服务账号，安装包里没有预置任何密钥。

还没有的话，推荐[硅基流动](https://cloud.siliconflow.cn/account/ak)（注册即送额度，够试很久）。也支持 OpenAI、DeepSeek、OpenRouter、月之暗面、智谱、阿里云百炼、Groq。

首次打开会有三步引导：**授权 → 接入模型 → 试一下**，跟着走完就能用。

推荐配置：

- 翻译 `deepseek-ai/DeepSeek-V3.2`
- 语音识别 `Qwen/Qwen3-ASR-1.7B`

## 怎么用

### 框选翻译 `⌘E`

按下后屏幕变暗，拖一个矩形框住要翻译的内容，松手即翻译。`Esc` 或右键取消。适合翻译图片、PDF、或任何选不中文字的地方。

### 划词翻译 `⌥S`

在别的 App 里选中一段文字，按下即翻译。它会先读取系统的选中文本，读不到时退回模拟一次复制——**并且会把你原本的剪贴板内容还原**，不会把你存着的东西冲掉。

超过 5000 字只翻译前面部分，浮窗里会注明。

### 语音输入 `Home`

在目标输入框里按一下开始、再按一下结束，也可以改成按住说话。说完文字直接填进光标处。

屏幕底部会出现一个黑色小浮条：左边取消、右边确认、中间是实时波形。**请等提示音响过再开口**——蓝牙耳机的通话链路需要一秒多才接通，之前的声音录不到；浮条在就绪前会写着「等提示音再说」。最长 5 分钟，快到上限时浮条才显示剩余秒数。

文字会直接填进光标处，**包括飞书、Electron、网页这类输入框**——这些界面不向系统暴露输入框内容，但按键本身不需要，所以照样填得进去。

只有三种情况确实填不进去，那时才会把整理稿复制到剪贴板并提示你按 `⌘V`：没给辅助功能权限、光标在密码输入框、或者触发时 Murmur 自己在前台。填入成功时不弹任何提示。

### 快捷键都能改

设置 →「翻译」页改前两个，「语音」页改第三个。**点一下快捷键那个框，直接按下新的组合键就录进去了**，不弹窗、不用确认；按 `Esc` 取消，恢复原来的。语音支持单独 `Home`、`Fn`、F1–F20，或修饰键加普通键。

### 历史与词典

设置侧栏的「历史记录」里能翻看过去的翻译和语音，两栏可切换，支持搜索、收藏、导出。

设置 →「语音」→「个人词典」可以把常用的人名、产品名、术语告诉 Murmur，整理文字时会参照它纠正听错的词。

## 隐私

**Murmur 没有服务器，不收集任何数据。**

你框选的图片、选中的文字、录下的语音，只会发送到**你自己配置的那个 AI 服务**（比如硅基流动），由那家服务处理。除此之外不经过任何第三方。

API Key 存在 macOS 钥匙串里，翻译历史和设置存在本机 `~/Library/Application Support/com.kangl.murmur/`，都不上传。

## 需要的系统权限

| 权限 | 用来做什么 | 不给会怎样 |
|---|---|---|
| 屏幕录制 | 截取你框选的那块屏幕 | `⌘E` 用不了 |
| 辅助功能 | 读取选中的文字、把结果填进输入框 | `⌥S` 和语音自动填入用不了 |
| 麦克风 | 语音输入录音 | 语音输入用不了 |

## 已知限制

- **不支持 Intel 芯片的 Mac。**
- **每次更新后，上面三项权限会全部失效，需要重新添加一遍**（要先删除再添加，只关开开关没用）。这是未做付费签名的代价，正式版会解决。
- 目前是内测版本，功能可用但仍在打磨。
